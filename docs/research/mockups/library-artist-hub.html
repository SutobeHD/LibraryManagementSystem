Reading this wireframe.

Amber = the single accent, exactly as in the app (primary action, active tab, warning). Round avatars, the mono track-count pill and the card shape are taken from the existing Library artist grid, so the Artist Hub reads as the same view family rather than a new page style.

Screens 1–3 are three states of the same Artists view (favourites list, artist drill-down, merge candidates); screen 4 is the Rekordbox projection panel. The suggestions panel is drawn twice on screen 1 so both of its tabs are visible on one static page.

Static wireframe — inline CSS only, no JS, no external assets. Mirrors the plan; regenerated if the plan changes.
